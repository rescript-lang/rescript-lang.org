This operator concatenates two `string` values. It remains supported, but since ReScript 12 the unified [`+`](./operators_integer_addition.mdx) operator can also concatenate strings and is preferred in new code.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let greetings = "Hello " ++ "world!"
```

```js
let greetings = "Hello world!";

export { greetings };
```

</CodeTab>
