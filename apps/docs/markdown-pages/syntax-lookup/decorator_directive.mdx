`@@directive` takes a string literal payload and emits it at the very top of the generated JavaScript file, before any imports.

This is useful for directives such as `'use client'` in React Server Components.

_Available since ReScript `10.1.4`._

### File-Level Example

<CodeTab labels={["ReScript", "JS Output"]}>

```res
@@directive("'use client'")
```

```js
"use client";
// Generated by ReScript, PLEASE EDIT WITH CARE
```

</CodeTab>

Since ReScript 12, `@directive` can also annotate a function expression. The directive is emitted at the start of the generated function:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let serverAction = @directive("'use server'") async (~name) => {
  "Hello " + name
}
```

```js
async function serverAction(name) {
  "use server";
  return "Hello " + name;
}

export { serverAction };
```

</CodeTab>

Place the attribute after the binding's `=` and directly before the function. Function directives work with synchronous and asynchronous functions and with multiple or labeled parameters.
