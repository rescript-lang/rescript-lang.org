A record type defines a fixed structure with named fields.

### Example

<CodeTab labels={["ReScript", "JS Output"]}>

```res
type myRecord = {
  name: string,
  age: int,
}

let myRecord: myRecord = {name: "Ada", age: 36}

let label = switch myRecord {
| {name, age} => name ++ " (" ++ Int.toString(age) ++ ")"
}
```

```js
let label = "Ada (" + (36).toString() + ")";

let myRecord = { name: "Ada", age: 36 };

export { myRecord, label };
```

</CodeTab>

### Nested Record Types

Since ReScript 12, record types can be declared inline inside another record type:

```res
type profile = {
  name: string,
  settings: {
    notifications: bool,
    theme: string,
  },
}
```

Nested record types are useful when the inner shape belongs only to its parent. If it needs to be referenced independently, give it a separate named type.
