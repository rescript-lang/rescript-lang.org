Since ReScript 12, `+` works with `int`, `float`, and `bigint`, and concatenates `string` values. The compiler specializes the operator from its operands.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let intResult = 1 + 2
let floatResult = 1.5 + 2.5
let stringResult = "Re" + "Script"
```

```js
let floatResult = 1.5 + 2.5;

let stringResult = "ReScript";

let intResult = 3;

export { intResult, floatResult, stringResult };
```

</CodeTab>

The older [`++`](./operators_string_concatenation.mdx) string concatenation operator is still supported.
