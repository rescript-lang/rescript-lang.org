> `%re` was removed in v13. Use a regular expression literal instead.

Regular expression literals create JavaScript regular expressions directly:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let regex = /^hello/
let result = regex->RegExp.test("hello world")
```

```js
let regex = /^hello/;

let result = regex.test("hello world");

export { regex, result };
```

</CodeTab>
