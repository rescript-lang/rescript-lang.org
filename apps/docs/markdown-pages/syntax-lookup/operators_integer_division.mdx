Since ReScript 12, `/` works with `int`, `float`, and `bigint`. The compiler specializes the operator from its operands.

Integer division truncates the result to an integer. Dividing an integer by zero throws a `Division_by_zero` exception.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let intResult = 3 / 2
let floatResult = 3.0 / 2.0
```

```js
let floatResult = 3.0 / 2.0;

let intResult = 1;

export { intResult, floatResult };
```

</CodeTab>
