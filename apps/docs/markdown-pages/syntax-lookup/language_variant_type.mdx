A variant type lets you represent different cases in one type.

### Example

<CodeTab labels={["ReScript", "JS Output"]}>

```res
type myResult<'a> =
  | MyVariant('a)
  | Error(string)

let response = MyVariant(42)

let message = switch response {
| MyVariant(value) => "Success: " ++ Int.toString(value)
| Error(err) => "Error: " ++ err
}
```

```js
let response = { TAG: "MyVariant", _0: 42 };

let message;

message =
  response.TAG === "MyVariant" ? "Success: " + (42).toString() : "Error: " + 42;

export { response, message };
```
