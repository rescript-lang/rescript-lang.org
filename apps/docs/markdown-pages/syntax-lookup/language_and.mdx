Use `and` to define multiple items in one mutually-recursive group.

### Example 1: `let rec ... and ...`

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let rec isEven = n => n == 0 || isOdd(n - 1)
and isOdd = n => n != 0 && isEven(n - 1)
```

```js
function isEven(n) {
  if (n === 0) {
    return true;
  } else {
    return isOdd((n - 1) | 0);
  }
}

function isOdd(n) {
  if (n !== 0) {
    return isEven((n - 1) | 0);
  } else {
    return false;
  }
}

export { isEven, isOdd };
```

</CodeTab>
