ReScript supports `while` loops. While loops execute its body code block while its condition is true.

A mutable binding can control whether a while loop continues.

### Example

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let shouldStop = ref(false)

while !shouldStop.contents {
  if Math.random() > 0.3 {
    shouldStop := true
  } else {
    Console.log("Still running")
  }
}

```

```js
let shouldStop = { contents: false };

while (!shouldStop.contents) {
  if (Math.random() > 0.3) {
    shouldStop.contents = true;
  } else {
    console.log("Still running");
  }
}

export { shouldStop };
```
