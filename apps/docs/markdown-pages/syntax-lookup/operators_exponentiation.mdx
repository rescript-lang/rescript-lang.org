`**` raises a base value to a power.

It supports `int`, `float`, and `bigint`.

### Example

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let i = 2 ** 3
let f = 2. ** 3.

open! BigInt
let b = 2n ** 3n
```

```js
let i = 8;

let f = 2 ** 3;

let b = 2n ** 3n;

export { i, f, b };
```

</CodeTab>
