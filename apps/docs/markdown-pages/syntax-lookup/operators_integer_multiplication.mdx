Since ReScript 12, `*` works with `int`, `float`, and `bigint`. The compiler specializes the operator from its operands.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let intResult = 2 * 3
let floatResult = 2.5 * 3.0
```

```js
let floatResult = 2.5 * 3.0;

let intResult = 6;

export { intResult, floatResult };
```

</CodeTab>
