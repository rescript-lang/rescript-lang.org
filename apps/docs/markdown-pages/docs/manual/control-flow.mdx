# If-Else & Loops

<div className="hidden">

```res prelude
@val external isMorning: bool = "isMorning"
@val external showMenu: bool = "showMenu"
@val external displayMenu: unit => unit = "displayMenu"
@val external startValueInclusive: int = "startValueInclusive"
@val external endValueInclusive: int = "endValueInclusive"
@val external testCondition: bool = "testCondition"
```

</div>

ReScript supports `if`, `else`, ternary expressions (`a ? b : c`), numeric `for` loops, `for of`, and `while`. Use `break` to exit a loop early and `continue` to skip to its next iteration.

The `switch` pattern supports a default case. Read more about [pattern-matching & destructuring](./pattern-matching-destructuring.mdx).

## If-Else & Ternary

ReScript's `if` is an expression; it evaluates to its body's content:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let message = if isMorning {
  "Good morning!"
} else {
  "Hello!"
}
```

```js
let message = isMorning ? "Good morning!" : "Hello!";

export { message };
```

</CodeTab>

**Note:** an `if-else` expression without the final `else` branch implicitly gives `()` (aka the `unit` type). So this:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
if showMenu {
  displayMenu()
}
```

```js
if (showMenu) {
  displayMenu();
}
```

</CodeTab>

is basically the same as:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
if showMenu {
  displayMenu()
} else {
  ()
}
```

```js
if (showMenu) {
  displayMenu();
}
```

</CodeTab>

Here's another way to look at it. This is clearly wrong:

```res nocheck
let result = if showMenu {
  1 + 2
}
```

It'll give a type error, saying basically that the implicit `else` branch has the type `unit` while the `if` branch has type `int`. Intuitively, this makes sense: what would `result`'s value be, if `showMenu` was `false`?

We also have ternary sugar, but **we encourage you to prefer if-else when possible**.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let message = isMorning ? "Good morning!" : "Hello!"
```

```js
let message = isMorning ? "Good morning!" : "Hello!";

export { message };
```

</CodeTab>

`if-else` and ternary are often replaced by [pattern matching](./pattern-matching-destructuring.mdx), which handles a wide range of conditional logic more expressively.

## For Loops

Numeric `for` loops iterate over integers from a starting value up to (and including) the ending value. The loop variable is local to the loop body.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
for i in startValueInclusive to endValueInclusive {
  Console.log(i)
}
```

```js
for (let i = startValueInclusive; i <= endValueInclusive; ++i) {
  console.log(i);
}
```

</CodeTab>

<CodeTab labels={["ReScript", "JS Output"]}>

```res
// prints: 1 2 3, one per line
for x in 1 to 3 {
  Console.log(x)
}
```

```js
for (let x = 1; x <= 3; ++x) {
  console.log(x);
}
```

</CodeTab>

You can make the `for` loop count in the opposite direction by using `downto`.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
for i in startValueInclusive downto endValueInclusive {
  Console.log(i)
}
```

```js
for (let i = startValueInclusive; i >= endValueInclusive; --i) {
  console.log(i);
}
```

</CodeTab>

<CodeTab labels={["ReScript", "JS Output"]}>

```res
// prints: 3 2 1, one per line
for x in 3 downto 1 {
  Console.log(x)
}
```

```js
for (let x = 3; x >= 1; --x) {
  console.log(x);
}
```

</CodeTab>

## For Of Loops

Use `for of` to visit each value in an array or an `iterable<'a>`, without managing an index:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
let names = ["Ada", "Grace", "Margaret"]

for name of names {
  Console.log(name)
}
```

```js
let names = ["Ada", "Grace", "Margaret"];

for (let name of names) {
  console.log(name);
}

export { names };
```

</CodeTab>

The loop binding must be a variable name or `_`. To destructure a value, do so inside the loop body:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
for entry of [("Ada", 36), ("Grace", 85)] {
  let (name, age) = entry
  Console.log(`${name}: ${age->Int.toString}`)
}
```

```js
for (let entry of [
  ["Ada", 36],
  ["Grace", 85],
]) {
  console.log(`${entry[0]}: ${entry[1].toString()}`);
}
```

</CodeTab>

For asynchronous iteration, see [For Await Of](./async-await.mdx#for-awaitof).

## Break & Continue

`break` exits the nearest enclosing loop immediately. `continue` skips the rest of the current iteration and starts the next one. Both work in numeric `for`, `for of`, `for await of`, and `while` loops.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
// Prints 1 and 3
for number in 1 to 5 {
  if number == 2 {
    continue
  }
  if number == 4 {
    break
  }
  Console.log(number)
}
```

```js
for (let number = 1; number <= 5; ++number) {
  if (number === 2) {
    continue;
  }
  if (number === 4) {
    break;
  }
  console.log(number);
}
```

</CodeTab>

In a numeric `for` loop, `continue` still advances the loop variable. In a `while` loop, it rechecks the condition, so make sure any necessary updates happen before `continue`.

You can also use `break` and `continue` inside a `switch` within a loop: they target the loop, not the `switch`. They cannot be used outside a loop or from a nested function to control an outer loop.

`break` and `continue` are reserved keywords, so they cannot be used as ordinary variable names.

## While Loops

While loops execute their body while the condition is true. The condition is checked before each iteration, so the body may never run.

<CodeTab labels={["ReScript", "JS Output"]}>

```res
while testCondition {
  Console.log("Still running")
}
```

```js
while (testCondition) {
  console.log("Still running");
}
```

</CodeTab>

### Exiting Early

Use `break` when the stopping condition is discovered inside the loop. There is no need for a separate mutable stop flag:

<CodeTab labels={["ReScript", "JS Output"]}>

```res
while true {
  if Math.random() > 0.3 {
    break
  }
  Console.log("Still running")
}
```

```js
while (true) {
  if (Math.random() > 0.3) {
    break;
  }
  console.log("Still running");
}
```

</CodeTab>
